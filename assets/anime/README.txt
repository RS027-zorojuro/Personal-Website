ANIME ARTWORK — drop your own image files in this folder
============================================================

The site looks for these exact filenames. Any image you place
here with the matching name will appear automatically — no code
changes needed. If a file is missing, that card just shows the
generated fallback (gradient + rank number) instead of a broken
image.

  01-one-piece.jpg           One Piece
  02-dragon-ball.jpg         Dragon Ball Series
  03-naruto.jpg              Naruto & Naruto Shippuden
  04-bleach.jpg              Bleach Complete Series
  05-fma-brotherhood.jpg     Fullmetal Alchemist: Brotherhood
  06-black-clover.jpg        Black Clover
  07-re-zero.jpg             Re:Zero
  08-kaguya-sama.jpg         Kaguya-sama
  09-gintama.jpg             Gintama
  10-initial-d.jpg           Initial D

Tips:
- Portrait-ish images (roughly 2:3 to 3:4) work best — the big
  stage and the thumbnails are both cropped with object-fit:cover,
  so a tall poster-style image will look better than a wide banner.
- .jpg, .png, or .webp all work — just keep the filename's base
  name and extension matching exactly (case-sensitive on most
  systems, including when you eventually host this anywhere other
  than your own machine).
- Keep files reasonably sized (a few hundred KB each is plenty for
  a personal site) so the page stays fast.
- Only use images you personally have the right to use.
